# MealRoute Git Lab

This starter project is a small nonprofit delivery coordination app used for practicing Git workflows.

Suggested branch/edit ideas for the lab:
- Update the default delivery window in `config.py`
- Change one message template in `notifications.py`
- Adjust a scheduler rule in `scheduler.py`
- Update stock warning text in `inventory.py`

Suggested conflict exercise:
- Create two branches that both edit the same line in `config.py` or the same message in `notifications.py`.
- Merge one branch into `main`, then merge the second branch and resolve the conflict.
